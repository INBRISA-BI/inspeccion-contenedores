# Calidad INBRISA
Sitio unificado: Inspección de contenedores, Fichas de calidad Contraste y Registro de producto off spec.
- index.html: portal con pestañas e inicio de sesión Microsoft (MSAL).
- contenedores.html + shim.js: tablero, lee los Excel de SharePoint en vivo.
- registro.html + registro.js: formulario que guarda en la lista CALI_ProductoOffSpec (Sitio Produccion).
- config.js: ids de la aplicación, listas y archivos.
